🇹🇷 Türkçe

MacRAR kuruldu

Kurulum tamamlandı. MacRAR şimdi açılıyor ve Kurulum Yardımcısı'nı gösteriyor.

  • Finder sağ tık menüsü etkinleştirildi ve Finder yeniden başlatıldı. Bir dosyaya sağ tıklayıp MacRAR · … girdilerini deneyin.
  • Kurulum Yardımcısı rar / unrar eksikse bunu ve kurulum komutunu gösterir.
  • Arşiv dosyalarına çift tıklayınca MacRAR açılsın istiyorsanız Kurulum Yardımcısı'ndan ya da Ayarlar'dan varsayılan uygulama olarak ayarlayın.

Bir sorun olursa kurulum günlüğüne bakın: /tmp/MacRAR-kurulum.log

🇬🇧 English

MacRAR is installed

The installation is complete. MacRAR is opening now and shows the Setup Assistant.

  • The Finder right-click menu is on and Finder was restarted. Right-click a file and try the MacRAR · … items.
  • If rar / unrar is missing, the Setup Assistant shows it and how to install it.
  • To open archives in MacRAR with a double-click, make it the default app in the Setup Assistant or in Settings.

If something goes wrong, see the installer log: /tmp/MacRAR-kurulum.log
